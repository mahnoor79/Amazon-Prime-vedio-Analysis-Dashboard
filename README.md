# 📊 Amazon Prime Video Dashboard – Power BI Project

## 📁 About the Dataset
This is a learning project created as part of an academic assignment. The dataset contains metadata about shows available on Amazon Prime Video. It includes essential information that helps analyze trends, user preferences, and content distribution across the platform.

## 🔍 Dataset Details
The dataset consists of various columns that help describe each show:

1) show_id – Unique identifier for each show.
2) type – Indicates whether the entry is a Movie or a TV Show.
3) title – Name of the show.
4) director – Name of the director (if available).
5) cast – Cast members featured in the show.
6) country – Country where the show was produced.
7) date_added – Date the show was added to Amazon Prime.
8) release_year – Year the show was originally released.
9) rating – Age rating (e.g., PG, R, 18+, etc.).
10) duration – Length of the movie or number of seasons (for TV shows).
11) listed_in – Genres or categories.
12) description – Short summary of the content.

## 🎯 Objective of the Dashboard
The goal of this dashboard is to visually analyze and understand the content available on Amazon Prime Video. Using Power BI, this dashboard highlights:

1) The distribution of content types.
2) Most common ratings and durations.
3) Content release trends over the years.
4) Relationships between show types, durations, and other attributes.

This project helps in practicing data cleaning, transformation, DAX calculations, and effective dashboard design.

## 📈 Dashboard Insights & Visuals

### 1. Count of Shows by Rating
A horizontal bar chart shows that most content is rated 13+, followed by 16+, and All Ages. This indicates Amazon Prime caters to a general and teenage audience.

### 2. Content Type Distribution

A donut chart clearly shows that:
Movies (80.82%) dominate the platform,
While TV Shows (19.18%) are in the minority.

### 3. Show Count by Duration and Type

This bar chart splits content by both type and duration. Notable patterns:
"1 Season" and "2 Seasons" dominate the TV Shows category.
Most Movies range around 90–92 minutes, which is a standard movie length.

### 4. Content Over Time
A line graph shows how Amazon Prime has rapidly increased its content library since the early 2000s, peaking in recent years. TV shows have also seen a steady rise.

## ✅ Conclusion

The Power BI dashboard provides a clear and interactive way to explore Amazon Prime Video's content offerings. It highlights:

1) Content is mostly Movies.
2) The 13+ rating is most frequent.
3) Most shows have standard durations.
4) There’s a sharp increase in content additions post-2010.
This dashboard not only summarizes content trends but also improves decision-making for content strategy, especially useful for media analysts and content planners.
